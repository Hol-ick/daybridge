# 2026-09-02 매일 기본 루틴을 영양제 먹기로 초기화

## 요청

기존의 매일 기본 일정 후보를 초기화하고 `영양제 먹기`를 매일 생성되는 기본 루틴으로 설정했다.

## 변경

- 기본 루틴 정본을 `영양제 먹기` 하나로 교체했다.
- 토·일을 포함한 요일 배열을 사용해 모든 날짜에 후보가 생성되도록 했다.
- 기존 스케줄러 계약과 맞추기 위해 예상 소요 시간은 25분으로 두었다. 실제 시간표를 만들지 않는 현재 설정에서는 오늘 할 일 카드 하나로 표시된다.
- 기존 날짜별 일정과 활동 로그는 보존했다. 이미 저장된 `리눅스 학습`은 과거 기록 또는 폐기 이력으로 소급 삭제하지 않는다.
- 기본 루틴 변경으로 통합 테스트 fixture가 추가 후보를 받지 않도록 현재 선택 업무에 `영양제 먹기`를 포함했고, 시간 없는 목록 모드의 현재 계약을 반영하도록 오래된 시간표 전제 테스트를 정리했다.

## 검증

- 기본 루틴 단위 테스트: 평일·주말 생성, 동일 제목 중복 억제, 사용자 지정 루틴 조건 통과.
- 실제 로컬 브리지 임시 데이터 검증: 빈 업무 보드에서 `routine-supplement` / `영양제 먹기` / `sourceKind=routine` 카드 1개 생성.
- 전체 Node 테스트 80건 통과.
- 퀘스트 컴파일러 테스트 8건 통과.
- 타입 검사와 Vite 빌드 통과.
