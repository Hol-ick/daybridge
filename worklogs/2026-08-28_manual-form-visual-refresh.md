# 2026-08-28 수동 추가 UI 시각 정리

## 현상

위젯의 수동 추가 폼이 어두운 배경 위에 여러 기본 버튼을 겹쳐 놓은 것처럼 보여 입력, 시간 단위 선택, 등록 동작의 우선순위가 약했다. 비어 있는 제목에서 등록 버튼이 지나치게 희미해 보이는 문제도 있었다.

## 조치

- 수동 추가 폼을 작은 명령 도크 형태로 정리하고, 입력 행과 시간 선택 행의 간격·높이·정렬을 고정했다.
- 입력창과 취소 버튼의 대비를 높이고, 취소 버튼은 원형 버튼으로 분리해 닫기 동작을 쉽게 인지하도록 했다.
- 시간 선택은 하나의 세그먼트 컨트롤로 묶고 선택된 50분 단위를 민트색으로 강조했다.
- 등록 버튼은 활성·비활성 상태 모두 읽을 수 있도록 색 대비를 조정하고, 호버·입장 애니메이션을 추가했다.
- 오버레이 전용 폼의 카드 내부 폭 제약과 기존 고대비 축소 규칙을 유지해 위젯 폭이 늘어나지 않게 했다.

## 검증

- Playwright 위젯 스모크 전체 흐름 통과(종료 코드 0).
- 수동 추가 폼의 오버레이 내부 경계, 바깥 클릭 시 닫힘, 재확장 시 초기화, 설정 모달 폭 회귀를 확인했다.
- 320×560 위젯 캡처에서 입력·시간 선택·등록 컨트롤이 한 카드 안에 정렬되고 한국어 텍스트가 읽히는 것을 확인했다.
