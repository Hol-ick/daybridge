# 2026-08-28 수동 추가 폼 폭 고정

## 현상

오버레이에서 `+`를 눌러 수동 추가를 열면 폼의 `modalOpen` 스타일이 위젯 폭을 420px로 바꿨다. 바깥을 눌러 목록을 접을 때도 입력 폼 상태가 남아 있어 최소화된 위젯이 넓은 상태로 유지될 수 있었다.

## 원인

- 수동 추가와 설정 모달이 같은 `modalOpen` CSS 클래스와 폭 상수를 공유했다.
- 확장 직후 설치된 바깥 클릭 리스너가 이전 `taskOpen=false` 값을 캡처해 입력 폼을 닫지 못했다.
- 절대 배치된 수동 추가 폼에 `width: 100%`가 남아 카드 오른쪽으로 넘칠 수 있었다.

## 조치

- 수동 추가는 항상 기본 오버레이 폭을 사용하고 설정 모달만 420px로 확장하도록 상태·스타일을 분리했다.
- 바깥 클릭·접기 시 수동 추가 상태를 초기화하고 최신 상태로 리스너를 갱신한다.
- 폼의 절대 배치 폭을 `left/right` 자동 계산으로 제한했다.

## 검증

- Playwright 위젯 스모크: 전체 흐름 통과, 종료 코드 0.
- 수동 추가를 연 상태의 카드 폭 288px, 폼의 카드 내부 수평 경계, 바깥 클릭 후 폼 제거 및 재확장 상태를 확인했다.
- 설정 모달 폭 420px 회귀와 기존 dashboard·drag·status 흐름도 함께 통과했다.
