# 2026-08-28 위젯 지속 표시 정책 정리

## 현상

위젯이 사라지는 현상을 조사한 결과, 릴리스 오버레이가 근무 종료 상태가 되는 순간 앱 종료 명령을 호출하고 있었다. 사용자는 퇴근 후에도 위젯을 계속 확인할 수 있어야 하며, 일정 데이터가 비어 있지 않은 상태에서도 창이 사라질 수 있었다.

## 원인

`ScheduleSurface`의 릴리스 오버레이 전용 감시가 `after_work` 상태에서 `exit_app`을 호출했고, 네이티브 명령은 `app.exit(0)`으로 전체 프로세스를 종료했다. 일정이 비어 보이는 현상과 관련된 브리지 포트 충돌은 별도 보조 이슈이며 위젯 창 종료의 직접 원인은 아니었다.

## 조치

- 퇴근 시각을 감시해 앱을 자동 종료하던 오버레이 전용 효과를 제거했다.
- 기존 `18:00` 기준 카운트다운 표시와 일정 새로고침·가시성 감시는 유지했다.
- 네이티브 종료 명령과 트레이의 명시적 종료 동작은 사용자가 직접 종료할 수 있도록 그대로 두었다.

## 검증

- Vite 빌드, 퀘스트 컴파일 테스트 8건, Playwright 위젯 스모크를 통과했다.
- 릴리스 위젯을 재빌드·재기동했으며, 2026-08-28 10:57 KST 현재 앱 프로세스와 브리지 health `ok / connected`를 확인했다.
- 렌더러에서 `workday_auto_exit_triggered`를 호출하는 경로가 제거되어 퇴근 후에도 오버레이가 계속 유지된다.
