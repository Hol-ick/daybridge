# Quiet internal UI

The settings screen repeated headings as descriptions, framed navigation as another card, displayed disabled time fields, and used two full-width utility buttons above a full-width save action. Other surfaces repeated the brand and a generic todo instruction card, with strong gradients, glows and decorative badges.

Settings now use short navigation, plain input rows, regular body weight, a compact interval field and a single footer with secondary tools and a right-aligned save button. Disabled meal inputs and untimed work-hour inputs are hidden without introducing storage mutations. Meal values remain in the existing controlled draft; the existing untimed-mode normalization is unchanged. Routine editing and storage-path disclosure stay available. Labels, toggle accessibility, error recovery and the single management close are retained.

Removed redundant helper sentences/menu subtitles, shortened memo and settings status messages, reduced palette card decoration, flattened widget/task form emphasis and removed the generic todo-mode instruction card and duplicate branding. Existing palettes and large Korean sans-serif memo text remain. Focus/drag/reorder and archive motion feedback remain; reduced-motion settings also cover pseudo-elements. The privacy draft now survives switching tabs before save, which the editing flow exposed.
