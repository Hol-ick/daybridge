# Daybridge 오버레이 텍스트 선택 고정 방지

- 날짜: 2026-08-24 KST
- 범위: 오버레이 제목이 드래그 중 선택된 채 남는 문제

## 현상

- 카드 배경을 드래그하거나 제목을 누르는 과정에서 브라우저 기본 텍스트 선택이 발생했다.
- 선택된 글자를 다시 해제하는 명시적 동작이 없어 제목 일부가 계속 강조돼 보였다.

## 원인

- 드래그 가능한 `.surface`에 `user-select: none`이 없었다.
- native drag를 시작하기 전 브라우저 selection을 정리하지 않았다.

## 수정

- 오버레이 전체에 `user-select: none`과 WebKit 호환 속성을 추가했다.
- pointerdown마다 현재 selection range를 제거한다.
- 스모크 테스트에서 CSS 선택 불가와 선택 영역 생성 후 카드 클릭 시 range 제거를 확인한다.

## 검증

- 좁은 오버레이 화면에서 제목 선택 상태가 유지되지 않는 흐름을 브라우저로 확인한다.
- 콘솔 오류 없이 기존 확장·접기·드래그 흐름이 유지되는지 함께 검사한다.
