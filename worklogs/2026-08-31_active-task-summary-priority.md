# 2026-08-31 진행 중 작업의 오버레이 메인 우선 표시

## 현상

목록 카드에서 작업을 `진행 중`으로 바꿔도, 접힌 위젯 메인에는 목록상 앞선 미완료 작업이 표시됐다.

## 확인한 근거

- 로컬 일정 응답에는 `사내 발표자료 준비`가 `in_progress`로 저장되어 있었다.
- 같은 응답의 앞선 미완료 항목은 `WIN재기동 메뉴얼 메일 발신`이었다.
- 기존 메인 후보 선택은 첫 번째 미완료 포커스 카드만 선택해 진행 상태를 고려하지 않았다.

## 변경

- 할 일 목록 모드의 메인 카드 우선순위를 `진행 중 → 미완료·진행 전 → 나머지 카드`로 정했다.
- 진행 중인 작업이 여러 개면 현재 목록 순서를 따른다.
- Playwright 공개 오버레이 제목 검사에서 진행 중인 `문서 검토`가 반드시 메인에 표시되도록 회귀 조건을 강화했다.

## 검증

- 수정 전 회귀 검사가 실패해, 진행 중 카드 대신 첫 카드가 선택되는 현상을 재현했다.
- 수정 후 해당 검사와 전체 위젯 스모크, 타입 검사, 퀘스트 컴파일러 테스트, 데스크톱 위치 테스트, 프로덕션 빌드를 통과했다.
