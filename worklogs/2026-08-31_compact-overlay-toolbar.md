# 2026-08-31 컴팩트 오버레이와 도구 행 정리

## 목적

짧은 오늘 일정에서 확장 오버레이 아래에 남는 빈 공간을 없애고, 작업 추가와 시간표 설정을 같은 크기의 즉시 조작 도구로 만든다.

## 구현

- 확장 오버레이 높이를 고정값 대신 현재 표시 카드 수로 계산한다.
  - 카드가 적으면 목록·도구 행을 감싸는 높이까지만 열리고, 남는 검은 영역을 만들지 않는다.
  - 카드가 많으면 기존 최대 높이에서 목록만 스크롤한다.
  - 설정 모달을 열 때는 기존 최대 높이를 유지한다.
- 하단 도구 행을 동일한 두 칸 그리드로 변경했다.
  - `+`와 설정 아이콘은 같은 폭, 같은 38px 높이의 버튼이다.
  - 작업 추가 아이콘 크기를 키우고, 수동 입력 양식은 도구 행 바로 위에 유지한다.
- 카드 수에 따른 실제 확장 높이와 두 도구 버튼의 크기 일치를 확인하는 Playwright 검사를 추가했다.

## 검증

- 타입 검사와 퀘스트 컴파일러 테스트 8건, 데스크톱 위치 테스트 2건을 통과했다.
- 빈 목록과 세 카드 일정의 오버레이를 렌더링해 확장 높이가 최대값보다 작고, 마지막 카드와 도구 행 사이에 빈 레이어가 남지 않는 것을 확인했다.
- 세 카드 상태 스크린샷에서 두 도구 버튼의 폭·높이가 동일한 것을 확인했다.
- 패키지 위젯을 다시 빌드·재기동했고, 로컬 일정 브리지가 정상 연결 상태임을 확인했다.

## 검증 범위 메모

- 기존 전체 Playwright 묶음의 카드 드래그 시나리오는 테스트 이벤트 전달 방식에 따라 간헐적으로 실패할 수 있어, 이번 변경에 직접 영향을 받는 확장·도구 행·빈 목록·세 카드 화면을 독립 검사로 추가해 검증했다.
