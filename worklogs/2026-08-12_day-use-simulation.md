# 2026-08-12 — 하루 사용 시뮬레이션

## 시나리오

1. 아침에 브리핑을 불러온다.
2. 순차 퀘스트의 단계를 순서대로 완료한다.
3. 완료된 퀘스트가 완료 그룹으로 이동하는지 확인한다.
4. 남은 작업을 내일로 미룬다.
5. 새로고침 후 완료·대기 상태가 유지되는지 확인한다.

## 발견과 수정

- 보고 응답마다 `INIT`가 확장 카드를 닫아, 한 작업을 이어서 처리하기 불편했다. 보고 응답에는 확장 상태를 보존하는 `SYNC`를 사용하도록 바꿨다.
- 여러 단계 보고가 겹치면 이전 응답이 최신 낙관적 상태를 덮어쓸 수 있었다. 보고 요청을 순서대로 보내고, 가장 최신 버전의 응답만 화면 상태를 확정하도록 조정했다.

## 결과

- 3단계 순차 퀘스트가 3/3 완료 후 완료 그룹으로 이동했다.
- 남은 퀘스트가 `deferred` 상태로 대기 그룹에 이동했다.
- 새로고침 후 완료 1개·대기 1개가 그대로 유지됐다.
- 브라우저 콘솔 오류는 없었다.
