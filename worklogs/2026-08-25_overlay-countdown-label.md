# Daybridge 빈 일정 카운트다운 라벨 표시

- 날짜: 2026-08-25 KST
- 범위: 일정이 없을 때 오버레이에 남은 시간의 의미가 보이지 않는 문제

## 현상

- 빈 일정 상태에서 위젯에는 `02:16`만 보여, 사용자가 점심까지인지 퇴근까지인지 알 수 없었다.

## 수정

- 기존 `다음 집중 시간 준비 중` 문구를 제거하고 왼쪽 제목 슬롯에 `점심시간까지`, 오른쪽 고정 슬롯에 큰 `02:16`을 배치했다.
- 오전 라벨을 `점심시간까지`, 오후 라벨을 `퇴근시간까지`로 명확히 바꿨다.
- 제목 슬롯 폭은 타이머 영역과 분리하고, 긴 작업명은 내부 marquee 애니메이션으로 이동해 전체 제목을 순차적으로 보여준다.
- 작업 중 완료 피드백은 기존 제목 영역에서 계속 표시한다.
- `block: null`인 focus 응답을 빈 상태로 해석하도록 수정해 fallback 문구가 다시 나타나지 않게 했다.
- smoke 테스트가 한 줄 카운트다운과 aria-label 전체 문구를 확인한다.

## 검증

- 빈 일정 브라우저 캡처에서 왼쪽 `점심시간까지`와 오른쪽 `02:01`이 서로 침범하지 않고 보이는 것을 확인했다.
- `pnpm build`, Node 테스트, 위젯 smoke, `cargo fmt --check`, `cargo check --locked`, `git diff --check` 통과
- 최신 Tauri 실행 파일과 NSIS 설치 패키지를 재빌드하고 실행했다.
