# 2026-08-31 todo 목록 순서 이동

## 현상

시간 설정이 없는 todo 목록에서 카드를 끌 수는 있었지만, 다른 카드 위에 놓아도 순서가 바뀌지 않았다.

## 원인

오버레이가 todo 모드의 드래그를 폐기 전용으로만 연결하고 있었고, 브리지의 일정 이동 API도 시간 슬롯이 없는 목록을 항상 거부했다. 목록을 재생성할 때도 날짜 기반 랜덤 순서가 다시 적용되어 사용자가 정한 순서를 유지할 경로가 없었다.

## 조치

- todo 모드에서도 열린 카드의 드래그 대상과 앞·뒤 위치 계산을 활성화했다.
- 시간표 모드와 분리된 todo 순서 이동 API를 추가해 시각을 만들지 않고 카드 `order`만 저장한다.
- 사용자가 재배치한 todo 순서를 다음 재생성·수동 추가 뒤에도 유지하고, 새 작업은 기존 목록 뒤에 추가한다.
- 휴지통 드래그와 todo 순서 이동을 같은 포인터 흐름에서 함께 사용할 수 있도록 했다.

## 검증

- todo 목록 순서 이동 API가 시각 필드를 만들지 않고 순서를 바꾸는지 통합 테스트로 확인했다.
- 이동 후 재생성해도 동일한 순서가 유지되는지 확인했다.
- Playwright 위젯 스모크에서 확장 완료 후 카드 드래그·대상 강조·이동 요청·휴지통 흐름을 확인했다.
- 전체 테스트·타입 검사·Vite 빌드·릴리스 위젯 빌드를 통과했고, 릴리스 위젯과 로컬 브리지 `ok / connected`를 확인했다.
