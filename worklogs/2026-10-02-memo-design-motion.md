# 메모 디자인·모션 개선: 2026-10-02

사용자가 기능 정상과 디자인·애니메이션 개선을 요청했다. 정본 계획의 공통 색/글꼴, 가벼운 목록과 넓은 본문, 간결한 날짜, 액션 구분, 좁은 창 탐색을 구현했다. 기존 저장·삭제·일정의 native 계약은 변경하지 않았다.

- 공통 CSS 토큰과 입력창 색·여백·포커스, SVG 액션과 위젯 세 아이콘 규격을 통일했다.
- 좁은 창에서 목록/상세를 전환하고 목록 복귀 포커스를 복원한다. resize는 선택과 본문을 보존한다.
- 저장/삭제 성공 후 접근성에서 제외된 퇴장 snapshot과 목록 FLIP을 적용한다. 부분 성공/실패는 메모를 유지한다. 모션 취소와 모션 감소가 lifecycle promise를 막지 않는다.
- 영상 검토에서 전체 창의 이동을 목록 재배치로 잘못 측정하는 현상을 발견해 목록 내부 offset을 기준으로 변경했다. 일반 상태의 불필요한 FLIP 반복을 검사한다.
- 초기 신규 날짜/모션4개 검사의 실패와 구현 후 통과를 확인했다. 전체 Node191/191, Rust36/36, type/frontend/Windows NSIS 및 독립 payload 검사 통과. 이후 UI 조정에는 관련 회귀와 화면 검사를 다시 수행했다.
- 격리 브라우저8개 조건(720/560/420px,100/150/200%,모션 감소)에서 선택·resize·포커스·저장 실패/부분 성공·정확한 TXT/자동 제거·즉시 삭제·일정 위젯 갱신과 페이지 오류0을 확인했다. 기존 메모 smoke11개 통과. 화면 캡처와 모션 연속 프레임을 검토했고 모션 감소에서는 Web Animations 호출0이다.
- 운영 UI와 최종 commit의 CI/설치본 적용은 후속 검증 대상이며 이 기록만으로 완료를 뜻하지 않는다. 예약 작업과 Windows 로그인 검증은 범위에서 제외한다. 원래 메모·일정·설정과 별도 미확인 이력을 보존한다.
