# Ctrl+D 큰 보관함/메모 통합: 2026-10-13

사용자가 작은 메모창 대신 큰 보관함의 오른쪽 입력 공간을 요청했다. archive 기본 창을900×720으로 확대하고 왼쪽220px 목록/새 메모, 오른쪽 입력 또는 기존 본문을 구성했다. 고배율/작은 작업 영역에서는 native 크기를 작업 영역 안으로 줄인다.

MemoSurface를 embedded로 재사용해 autosave·세션 ACK·한글 조합·실패 보존을 유지한다. 편집기는 기존 메모 탐색 중에도 mounted 상태로 남고 draft를 보존한다. 새 메모 버튼은 이전 글을 보관한 뒤 빈 세션을 연다. Ctrl+D/트레이 메모는 같은 archive 창을 열고 편집기에 초점을 맞춘다. 반복 호출은 현재 작성 중 글을 유지한다.

native 저장 명령의 caller는 memo/archive로 한정한다. 세션을 만든 창을 lifecycle에 기록해 명시적 종료도 해당 편집기에 요청한다. X/Esc/native Alt+F4는 편집기 최종 보관 ACK 후 큰 창을 숨긴다. 활성 draft가 있으면 직접 archive 숨김을 거절한다. 창을 숨기지 않고 세션을 보관하는 경우 hideWindow=false로 release하고 종료 ACK를 확인한다. 닫기 실패는 예외를 부모로 전달해 입력/창을 유지한다. 지연 초기 open·새 메모 전환·닫기/재호출·IME Esc를 보호한다.
