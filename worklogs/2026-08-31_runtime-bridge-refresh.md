# 2026-08-31 런타임 브리지 새로고침

## 현상

todo 목록의 카드 순서 변경 수정이 소스와 자동화 검증에서는 통과했지만, 실행 중인 위젯에서는 반영되지 않았다.

## 확인한 원인

실행 중이던 로컬 브리지는 순서 변경 수정 커밋보다 먼저 시작된 프로세스였다. 위젯을 다시 열어도 정상 응답 중인 기존 브리지를 재사용하도록 되어 있어, 이전에 메모리에 로드된 일정 이동 로직이 계속 제공됐다. 당시에는 예전 위젯 프로세스도 함께 남아 있었다.

## 조치

- 검증한 Daybridge 로컬 브리지 프로세스만 종료하고, 저장된 일정·보드·이벤트 파일은 수정하지 않았다.
- 릴리스 위젯을 다시 시작해 현재 소스의 브리지를 새로 기동했다.
- 중복으로 남은 이전 위젯 프로세스를 종료해 위젯과 브리지를 각각 한 개로 정리했다.

## 확인

- 새 브리지의 시작 이벤트와 새 프로세스 시작 시각을 확인했다.
- 로컬 브리지 health 응답이 `ok`, 연결 상태가 `connected`임을 확인했다.
- 현재 todo 일정은 시간 미배정 상태로 두 카드가 보존된 것을 확인했다.

## 남은 확인

- 실제 위젯에서 한 카드를 다른 카드의 위쪽 또는 아래쪽 절반에 놓았을 때 순서가 즉시 바뀌는 사용자 상호작용을 확인한다.
