# Daybridge 오버레이 압축형 타이포그래피 조정

- 날짜: 2026-08-25 KST
- 범위: 288px 오버레이에서 글자가 작게 보이는 문제

## 관찰

- 실제 화면에서는 접힌 카드의 제목·시간과 펼친 패널의 일정 텍스트가 위젯 크기에 비해 작게 보였다.
- 전체 창을 키우지 않고 글자만 키워야 하므로, 행 높이와 내부 여백은 함께 압축해야 했다.

## 수정

- 접힌 카드 제목을 17px, 시작 시각을 12px, 퇴근 카운트다운을 27px로 키웠다.
- 펼친 패널의 헤더를 13px, 일정 시작 시각·작업명을 각각 17px로 키웠다.
- 행 간격, 행 패딩, footer 여백을 줄여 접힘 64px·펼침 520px 크기는 유지했다.
- smoke 테스트가 새로운 최소 글자 크기를 회귀 기준으로 확인하도록 갱신했다.

## 검증

- `pnpm build` 통과
- Node 테스트 통과
- `python scripts/widget-smoke.py` 통과
- `cargo fmt --check` 및 `cargo check --locked` 통과
- `git diff --check` 통과
- 접힌·펼친 브라우저 캡처를 시각적으로 확인했으며, 텍스트가 더 크게 보이고 기존 폭·높이·하단 고정은 유지됐다.
- 최신 코드로 Tauri 실행 파일과 NSIS 설치 패키지를 재빌드했다. 첫 시도는 기존 실행 중 프로세스가 파일을 점유해 실패했지만 해당 Daybridge 프로세스를 종료한 뒤 재시도하여 성공했다.
