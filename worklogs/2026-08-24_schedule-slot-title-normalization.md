# 2026-08-24 — 시간표 단위·제목 정규화

## 목적

브리핑 원문이 그대로 시간표에 노출되거나 현재 시각에서 임의의 분 단위로 시작하는 문제를 줄이고, 사용자가 바로 실행할 수 있는 한 시간 단위의 시간표로 통일한다.

## 반영

- 집중 블록을 `HH:00–HH:50` 한 단위로 고정했다. 현재 시각, 캘린더 바쁨 구간, 잠긴 블록 뒤에는 다음 정각으로 건너뛴다.
- 기존 `25분` 설정을 저장소에서 읽더라도 새 규칙인 50분 단위로 자동 정규화한다. 설정 화면에는 `매시 00분–50분`만 표시한다.
- 시간표 경계에 짧은 제목 변환기를 추가했다. Supabase/Kiosk/택배/대화 coverage/운영 DB 같은 반복 패턴은 짧은 실행 라벨로 만들고, 원문은 AIHUB 보드에서 계속 확인할 수 있다.
- Playwright 대시보드 빈 상태 fixture를 실제 일정과 분리해, 실제 보드가 생성되어도 빈 상태 회귀 검사가 흔들리지 않게 했다.

## 검증

- 전체 Node 테스트 38개 통과.
- TypeScript 검사와 Vite production build 통과.
- Playwright 대시보드·오버레이 smoke 통과, 콘솔 오류·실패 요청 없음.
- 실제 local bridge 재생성 결과: `15:00–15:50 Supabase 백업 확인`, `16:00–16:50 고객 택배 접수 검증`, `17:00–17:50 대화 coverage 확인` 등으로 저장됨.

## 남은 확인

- 캘린더가 연결된 날에는 바쁨 구간에 의해 일부 정각 슬롯이 건너뛰는지 실제 계정 데이터로 추가 관찰한다.
