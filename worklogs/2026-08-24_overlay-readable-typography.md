# 오버레이 가독성 개선

## 변경

- 네이티브 오버레이와 카드의 크기를 `288×64px`로 맞췄다.
- 한글 본문 글꼴을 설치된 `Noto Sans KR` 우선으로 정리하고, 제목·버튼을 800 굵기로 올렸다.
- 시간 정보는 `Cascadia Mono` 계열의 유틸리티 서체로 분리했다.
- 퇴근 카운트다운을 `HH:MM` 형식의 22px 타이머로 바꿔 한눈에 읽히도록 했다.
- 활성 집중 블록에서는 `완료`를 유지하고, 빈 시간대에서는 `열기` 버튼을 없애 타이머를 배치했다.
- 일정 시간이 없는 빈 상태에서는 `시간표 확인` 보조 문구를 렌더링하지 않는다.
- 요약 카드를 클릭하면 같은 폭의 `288×520px` 관리 패널이 위로 확장되고, 하단 요약 행은 고정된다.
- 확장 패널은 시간표 블록별 완료·미룸, 재배치, 전체 시간표 열기를 제공하며 CSS 높이·투명도 애니메이션을 사용한다.
- 시간표 설정 모달은 `288px` 폭과 2열 입력 행으로 압축해 작은 화면에서도 한 번에 조작할 수 있게 했다.
- Tauri `core:window:allow-set-size` 권한을 추가해 실제 네이티브 창 높이 변경을 허용했다.
