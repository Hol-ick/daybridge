# 2026-08-12 — 한국어 위젯과 브리핑 불러오기

## 변경

- 위젯의 날짜, 그룹명, 상태 조작 라벨을 한국어로 통일했다.
- 상단의 수동 퀘스트 입력 영역을 `브리핑 불러오기` 버튼으로 바꿨다.
- 버튼을 누르면 현재 날짜의 Daybridge 보드를 브리지에서 다시 읽고, 불러오는 동안 중복 요청을 막는다.
- 데모 보드의 제목·단계·완료 조건도 한국어 샘플로 정리했다.
