# Daybridge 옵션의 위젯 새로고침

- 날짜: 2026-08-27 KST
- 범위: 위젯이 사라졌을 때 설정 화면에서 즉시 표시를 복구하고 최신 일정 상태를 다시 읽는 수동 새로고침

## 결정 및 구현

- 대시보드의 `시간표 설정` 모달과 오버레이의 `시간표 설정` 모달에 `위젯 새로고침` 버튼을 추가했다.
- 버튼은 저장 동작과 분리되어, Tauri 릴리스에서는 native `show_overlay`로 위젯을 표시·최상위 순서로 되돌린 뒤 일정과 캘린더 상태를 다시 읽는다.
- 설정 모달이 열려 있을 때는 설정 값도 다시 읽어 화면과 저장 대상의 상태를 맞춘다.
- 실행 중에는 `새로고침 중…`으로 버튼을 잠그고, 성공·실패를 화면 알림과 런타임 이벤트(`overlay_manual_refresh`, `overlay_manual_refresh_error`)로 남긴다.
- 데이터 재조회 실패를 성공으로 기록하지 않도록 각 응답을 확인한 뒤 성공 이벤트를 기록한다.

## 검증

- `pnpm build`: 성공.
- `pnpm test:compiler`: 8개 테스트 전부 통과.
- `scripts/widget-smoke.py`: 기존 대시보드·오버레이·드래그 회귀와 새로고침 버튼 표시·클릭 흐름 통과.
- Playwright 브라우저 테스트: 대시보드와 오버레이 설정에서 버튼 노출·클릭·버튼 복귀를 확인했고 콘솔 오류·실패 요청은 0건이었다.
- 설정 화면 시각 점검: 새 버튼이 저장 버튼과 분리된 보조 동작으로 보이며, 오버레이 모달에서도 동일한 계층으로 표시된다.
- `pnpm build:widget`: 새 릴리스 실행 파일과 NSIS 설치 파일 생성 성공.
- 새 릴리스 프로세스가 재기동되었고, bridge `GET /api/schedule?date=2026-08-27`가 HTTP 200으로 응답했다.

## 남은 확인

- 실제 사용 중 위젯이 숨겨진 상태에서 대시보드 설정의 버튼을 누르면 native 창이 다시 표시되는지 현장 화면에서 한 번 더 확인한다.
- Google Calendar OAuth가 설정되지 않은 환경에서는 기존처럼 캘린더 상태가 `attention`으로 남는다.
