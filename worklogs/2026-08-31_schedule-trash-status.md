# 2026-08-31 일정 폐기와 완료 상태 보존

## 현상

시간 설정이 비어 있는 오늘 할 일 목록에서 카드를 끌어 휴지통에 놓을 수 없었고, 일정 카드 완료 후 새 작업을 추가하면 완료 상태가 다시 열린 상태처럼 보였다.

## 원인

오버레이는 시간표 모드에서만 드래그를 활성화하고 있어 todo 모드에는 휴지통 진입 경로가 없었다. 일정 상태 보고는 일정 JSON의 블록만 갱신하고 원본 퀘스트에는 반영하지 않았으며, 같은 ID의 일정 Markdown을 다시 읽을 때 입력값이 저장된 상태를 덮어쓸 수 있었다. 재배치 시 완료 블록을 보존하는 조건도 잠금·경과 시간에만 한정되어 있었다.

## 조치

- todo 모드의 열린 카드도 폐기 목적의 드래그를 지원하고, 드래그 중 동일한 크기의 휴지통 영역을 표시하도록 수정했다.
- 일정 블록 상태 보고를 원본 퀘스트의 상태·잔여량·보고 이력에 동기화했다.
- 일정 Markdown은 제목·구조 입력으로만 사용하고, Daybridge의 상태·보고·진척 데이터는 우선 보존하도록 병합 규칙을 바꿨다.
- 재생성 때 완료·보류·건너뜀 블록을 유지해 새 일정 추가나 재배치로 상태가 되살아나지 않게 했다.

## 검증

- 임시 브리지 데이터에서 완료 보고 → 일정 추가 → 재생성 후 완료 상태 보존을 통합 검증했다.
- 시간 없는 todo 목록의 포인터 드래그 → 휴지통 활성화 → 폐기 API 호출을 Playwright 스모크로 검증했다.
- 전체 Node 테스트 68건, Vite 타입·프로덕션 빌드, 릴리스 위젯 빌드를 통과했다.
- 릴리스 위젯을 재기동했고 로컬 브리지 health `ok / connected`, 오늘 일정 4건을 확인했다.
