# 2026-08-31 Daybridge 활동 로그

## 목적

위젯에서 사용자가 실제로 조작한 작업 이력을 다른 Codex 세션이 로컬에서 안전하게 읽을 수 있도록 한다.

## 구현

- 날짜별 append-only NDJSON 정본과 사람이 읽는 Markdown 보기를 `activity/` 아래에 생성한다.
- 성공한 수동 추가, 상태 변경, 카드 순서 변경, 오늘 목록 제거, 재배치, 시간표 설정 변경을 각각 한 건의 활동 record로 남긴다.
- 브리지의 `GET /api/activity?date=YYYY-MM-DD`에서 같은 기록을 반환한다.
- 이메일, 전화번호, 비밀값, 로컬 절대 경로는 로그에 기록하기 전에 치환한다.

## 해석 경계

활동 로그는 Daybridge에서 사용자가 수행한 조작의 receipt다. 완료 표시가 외부 시스템의 실제 완료를 자동으로 증명하지는 않는다.

## 검증

- 활동 로그 모듈이 Markdown과 NDJSON을 함께 만들고 민감한 경로를 치환하는지 확인했다.
- 수동 추가, 상태 변경, 순서 변경, 오늘 목록 제거, 시간표 설정 변경 뒤 활동 API에서 action record를 확인했다.
- 전체 Node 테스트 35건, 타입 검사, Vite 빌드를 통과했다.
