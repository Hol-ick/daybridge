# Daybridge 확장 시간표 시작 시각 표시

- 날짜: 2026-08-24 KST
- 범위: 오버레이 확장 패널의 일정 행

## 결정

- 일정 행에는 종료 시각과 구간 대시를 표시하지 않는다.
- 시작 시각만 `17:00`처럼 크게 보여 작업 목록을 빠르게 훑을 수 있게 한다.
- 제목과 완료·미룸 조작은 같은 행에 유지한다.

## 구현

- `OverlayScheduleItem`이 종료 시각을 렌더링하지 않고 시작 시각만 전달한다.
- 시작 시각 열을 62px로 줄이고 글자 크기를 16px로 키웠다.
- 스모크 테스트에서 종료 구분자 부재와 시작 시각 글자 크기를 검사한다.

## 검증

- 브라우저 확장 패널에서 `17:00`, `18:00` 같은 시작 시각만 보이는지 시각 확인한다.
- 제목의 한글·영문 혼합과 조작 버튼이 잘리지 않는지 확인한다.
