# Compact Accordion Quests

**목표:** 접힌 상태에서는 여러 퀘스트 카드가 작게 보이고, 한 카드를 누르면 그 카드 자체가 크게 펼쳐져 설명과 축소된 서브 퀘스트를 조작할 수 있게 한다.

**구조:** 기존 board와 자동 progress receipt 계약은 유지한다. 화면 상태는 `expandedQuestId` 하나만 소유하며, 한 번에 한 부모 퀘스트만 열 수 있다. 상태 전환·출처·XP 같은 보조 UI는 노출하지 않는다.

## 작업

### 1. 카드 아코디언 렌더링

- [ ] 부모 퀘스트를 작은 접힌 카드 목록으로 렌더링한다.
- [ ] 클릭한 카드의 헤더 높이와 상세 영역을 애니메이션으로 크게 확장한다.
- [ ] 확장 영역에 요약·완료 기준·축소된 서브 퀘스트 카드를 표시한다.
- [ ] 서브 퀘스트 클릭은 원래 부모 퀘스트의 자동 receipt 기록을 유지한다.

### 2. 컴팩트 디자인 및 회귀 테스트

- [ ] 카드 덱을 좁은 간격, 작은 서브 카드, 한 장만 열린 상태로 재구성한다.
- [ ] reduced-motion과 키보드 포커스를 유지한다.
- [ ] 브라우저 스모크 테스트가 접힌 카드, 열린 카드, 서브 퀘스트 조작, 단일 확장 상태를 검증하게 한다.
- [ ] 빌드·컴파일러 테스트·화면 캡처를 실행하고 worklog/status를 갱신한다.
