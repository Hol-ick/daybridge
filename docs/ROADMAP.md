# Roadmap

## M0 — Workspace and preview

- Vite + TypeScript project
- Interactive visual preview using demo data
- Product and privacy boundaries
- Action-list contract

## M1 — Reliable quest compiler ✅

- Sanitized note fixtures
- Deterministic extraction and normalization
- Duplicate detection and policy-statement rejection
- Ranking with transparent evidence
- Schema validation and failure fallback
- AIHUB handoff collector and morning/closeout synthesis

## M2 — Local widget behavior ✅ (browser surface)

- File-backed action-list loading
- Local receipts for complete, progress, pause, block, and confirmation
- Achievement points and checklist progress
- Source-reference opening
- Freshness and stale-data state

## M3 — Windows desktop shell

- Tauri wrapper
- Tray, autostart, persisted position, and compact widget mode
- Explicit local-path setup flow

## M4 — Optional extensions

- Multiple note sources
- Calendar-aware but consented prioritization
- A review queue for low-confidence candidates
- Optional encrypted sync
